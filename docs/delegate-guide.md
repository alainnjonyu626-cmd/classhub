# Your ClassHub: delegate guide

You update the class by editing a Google Sheet on your phone. The class page follows.

## 1. Your two links

- **Hub link:** share this with your class, in the WhatsApp group.
- **Sheet link:** keep this one private. Only you can edit it.

## 2. Golden rules

1. **Never change row 1.** The column names must stay exactly as they are.
2. **Dates look like `2026-10-22`.** Year, month, day.
3. **Times look like `14:30`.** 24-hour clock.
4. **Use the dropdowns** when a cell has one (category, type, day).
5. **Yes/no cells** take `yes` or `no`.

## 3. Add an announcement

1. Open the tab **announcements**.
2. Go to the first empty row at the bottom.
3. `id`: the last number plus 1. Never reuse a number.
4. Fill `date`, `title`, `body` and pick a `category`.
5. To pin it to the top of Home, write `yes` in `pinned`. Only the newest pinned one shows on Home.
6. Optional: `where` (the venue), `when` (the time in words), `attachment` (a Drive link).

## 4. Change the timetable

Open the tab **timetable** and edit the row. To remove a class, delete the whole row. To add one, fill `day`, `start`, `end` and the course `code`.

## 5. Add a deadline

Open the tab **deadlines** and add a row: `title`, `type` (test, assignment, exam...), `date` and, if you know it, `time` and `venue`. When it is finished, write `yes` in `done`.

## 6. Add a handout

1. Upload the file to the Drive folder **Handouts**.
2. Tap Share, then Copy link. The link must say "Anyone with the link can view".
3. Open the tab **handouts**, add a row, and paste the link in `link`. Fill `code` and `title`.

## 7. When will students see it?

Usually within a few minutes. A student can open **More** and tap **Refresh data now** to get it straight away.

## 8. Something looks wrong?

- Open **More** in the hub. The note at the bottom says if any rows were skipped. A skipped row is usually a missing title, a date in the wrong format, or a time that is not `HH:MM`.
- Fix that row in the sheet and refresh.

## Please do not

- Put results, marks or private details in the sheet. Anyone with the hub link can read what is in it.
- Share the sheet link with the class.
