Questions

Do students need to download anything?

No. They open the link in their phone browser. They can also add it to the home screen, and it opens like an app.

Our school only has some sections. Can we still use it?

Yes. A school can have only general classes, only technical or commercial ones, or even a single class. Each class gets its own page, and anything you don't use, like past papers or the Parents' corner, can be switched off so it never shows.

Who can edit?

Only the delegate or school office (and us). Everyone else just views the page.

What if we have no data?

After the first visit the hub keeps a saved copy, so students can still read the latest info offline.

Is it private?

Anyone with the link can view it, so we never put private information on it, like results or individual fees. Share the link only with your class.
